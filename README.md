# Friends Tableau Dashboard

Pair data visualization project focused on analyzing the TV series **Friends** through an interactive Tableau dashboard, visual storytelling and audience-related insights.

This project was developed during the **Adalab Data Analytics & AI Bootcamp** as a pair project.

## Overview

The goal of this project was to explore and visualize key data related to the TV series **Friends**, using Tableau to transform structured data into clear, interactive and business-oriented dashboards.

The analysis focuses on understanding patterns across episodes, seasons, characters, ratings and audience behavior, while applying data visualization best practices and storytelling techniques.

---

## Project Context

This was a **pair project** developed during the Adalab Data Analytics & AI Bootcamp.

The project simulates a real data visualization scenario where an interactive dashboard is used to communicate insights clearly to a non-technical audience.

---

## Objective

The main objective was to design an interactive Tableau dashboard capable of answering questions such as:

- How do ratings evolve across seasons?
- Which episodes stand out the most?
- Are there differences in audience or ratings between seasons?
- Which characters have greater presence or protagonism across the series?
- What patterns can be identified in the performance of the series over time?
- How can visual storytelling help communicate insights effectively?
